# Steam Account Viewer

Локальное Tauri-приложение, которое показывает все аккаунты из `Steam/config/loginusers.vdf`: текущий аккаунт и историю ранее использованных аккаунтов. Данные никуда не отправляются.

## Возможности

- поиск стандартной папки Steam на Windows, Linux и macOS;
- имя профиля, логин, Steam ID, локальный аватар и дата последнего входа;
- отметка текущего аккаунта, когда Steam запущен;
- фильтры и поиск;
- безопасное удаление записи из `loginusers.vdf` только после ввода `подтверждаю`;
- резервная копия `loginusers.vdf.sav-backup` перед изменением;
- игры, папка `userdata`, облачные и локальные сохранения не удаляются.

## Запуск

Нужны Node.js, Rust и системные зависимости Tauri 2.

```bash
npm install
npm run dev
```

## Сборка Windows EXE

```bash
npm install
npm run build
```

Готовый файл появится в `src-tauri/target/release/steam-account-viewer.exe`. Скрипт специально использует `--no-bundle`, поэтому не требует иконок установщика.

## Если Steam установлен нестандартно

Укажите переменную окружения `STEAM_PATH` с полным путём к папке Steam.

## Как определяется текущий аккаунт

Приложение читает все сохранённые записи из `loginusers.vdf`. На Windows текущая запись сопоставляется с `AutoLoginUser` в реестре и запущенным процессом Steam; на других системах используется `MostRecent` при запущенном Steam. Остальные записи отображаются как история.

Перед удалением локальной записи Steam нужно полностью закрыть, иначе клиент может восстановить файл. Приложение удаляет только запись входа и связанный локальный аватар, но не трогает `userdata`, игры или сохранения.
